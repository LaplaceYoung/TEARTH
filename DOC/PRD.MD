🌍 产品需求文档 (PRD)：个人书影音3D地理志
1. 产品概述
产品定位：一个基于浏览器的 3D 互动地球仪，作为个人的地理文化记忆载体。用户可以按国家板块记录并回顾与该国相关的书籍、电影、音乐，辅以评分、图文评价。
目标用户：仅个人使用。
核心亮点：双重手绘质感主题（复古/现代）、基于记录数量的颜色热力学渐变、沉浸式的3D运镜交互、纯本地化数据存储（隐私最高，零服务器成本）。
2. 核心功能模块划分
2.1 3D地球与视觉交互模块
这是网站的核心视觉载体，需实现精细的地理板块划分和丝滑的镜头语言。
双主题切换（全局配置）：
主题 A：大航海羊皮纸（复古手绘）
海洋为泛黄羊皮纸纹理，国家边界为粗糙的墨水钢笔线条。
热力图颜色：按书影音数量从“浅棕/米色”向“深褐色/复古红”渐变。
主题 B：绘本水彩（清新现代）
海洋为低饱和度水彩蓝，国家边界为彩色蜡笔质感线条。
热力图颜色：按数量从“浅白/淡彩”向“高饱和水彩（如明黄、翠绿、橘红）”渐变。
热力图渲染逻辑：
地球初始状态下，读取本地库计算每个国家的书影音总数。
划分为 0, 1-3, 4-10, 10+ 四个阈值级别，对应四个梯度的手绘填充色。
交互与运镜：
悬浮（Hover）：鼠标移至某国家板块，该板块外发光或线条加粗，跟随鼠标显示该国名称及书影音总数。
点击（Click）：
镜头触发平滑缓动（Tween），自动将所点击国家旋转并放大至屏幕中央。
屏幕侧边（右侧或左侧）平滑滑出「国家信息与内容面板」。
拖拽与缩放：支持鼠标左键拖拽旋转地球，滚轮缩放查看细节。
2.2 数据录入模块（侧边面板）
点击国家后在侧边栏进行内容添加。支持“书籍(Book)、电影(Movie)、音乐(Music)”三大类别并行操作。
双轨信息获取（录入方式）：
方式一：API 搜索拉取（推荐）
提供搜索框，下拉选择媒体类型（书/影/音）。
输入名称后，前端调用第三方公开 API（如 TMDB、Google Books、iTunes/Spotify 开放接口）拉取结果列表。
点击结果，自动填充封面图、标题、作者/导演、简介等元数据。
方式二：纯手动录入
用户手动输入标题、作者/创作者。
支持本地选择图片上传作为封面图（前端将图片转为 Base64 或 Blob 存入本地数据库）。
评价系统：
评分：传统的 1-5 星交互（支持半星）。
文字评价：多行文本框，用于记录感想。
附件插图：在评价区下方提供“添加图片”按钮，支持上传多张剧照/风景图/书摘截图作为评价补充。
数量规则：无数量限制，同一个国家可无限量添加不同类型的作品。
2.3 内容展示模块
查看已录入的国家数据。
列表视图（国家概览）：
侧边栏顶部显示：国家名称（手绘字体）、国旗、已收录总数统计（如 📚 5 🎬 12 🎵 3）。
下方瀑布流或列表展示已录入的作品卡片（包含封面、标题、星级、短评摘要）。
详情视图：
点击某一张卡片，侧边栏内容切换或弹出浮层，展示完整的评价、大尺寸封面、所有附加图片。
提供“编辑”和“删除”按钮。
2.4 本地存储与数据管理模块
因明确要求“录入并本地储存”，需解决浏览器缓存的持久性和容量问题。
底层技术：使用浏览器的 IndexedDB（相较于 LocalStorage的 5MB 限制，IndexedDB 支持存储几百 MB 甚至 GB 的数据，非常适合存储包含图片的本地评价）。
数据安全与导入/导出（核心必备功能）：
一键导出：提供“导出数据”按钮，将全部评级、文字甚至图片打包生成一个 .json 或 .zip 文件下载到电脑硬盘（防止清空浏览器缓存导致心血丢失）。
一键导入：在新电脑或新浏览器上，上传此备份文件，瞬间恢复整个地球仪的状态。
3. 用户操作主流程 (User Flow)
打开网站：加载 3D 地球，读取本地 IndexedDB，根据现有数据渲染国家手绘颜色。
寻找目标：鼠标转动地球，找到目标国家（如：俄罗斯）。
聚焦国家：点击俄罗斯 -> 镜头平滑放大居中俄罗斯 -> 右侧滑出面板，显示“俄罗斯 0 记录”。
添加内容：
点击“+ 添加作品”。
选择“电影”，在搜索框输入“《塔可夫斯基：乡愁》”。
选择 API 返回的正确结果，自动补全封面和基础信息。
填写评价：给出 5 星，写下一段影评，并手动上传一张电影截图。
保存：点击保存。数据写入本地数据库。
视觉反馈：右侧列表多出该电影卡片；同时，背景中的俄罗斯板块颜色因为数量从 0 变 1，颜色瞬间加深一层。
备份：定期在设置栏点击“导出数据存档”到本地电脑。
4. 技术可行性与数据结构建议 (供后续开发参考)
4.1 第三方 API 建议（前端直接调用）
由于没有后端，需选用支持前端跨域（CORS）或提供 JSONP 的免验证/轻验证接口：
电影：TMDB (The Movie Database) API (免费，需注册申请一个 key 填在前端设置里)。
书籍：Google Books API (无需鉴权即可进行基础搜索) 或 OpenLibrary API。
音乐：iTunes Search API (完全免费开放，支持跨域搜索专辑、艺术家)。

5. 后续开发推进建议
当这份 PRD 确认无误后，你如果要找工程师或者使用 AI 生成代码，可以按照以下三个冲刺阶段（Sprint）进行：
Sprint 1：建立视觉基座。利用 Three.js + GeoJSON 绘制 3D 地球，实现国家点击与镜头拉近，跑通主题 A 和主题 B 的渲染着色器（Shader）。
Sprint 2：搭建数据管理。建立前端侧边栏 UI，封装 IndexedDB 操作逻辑，实现手动录入、图片读取、5 星打分和列表展示。实现数据和地球颜色联动的逻辑。
Sprint 3：接入搜索生态。对接 TMDB、Google Books 和 iTunes 的开放 API，完善搜索填充功能。最后完成“数据导出/导入”功能，确保产品具备实际长期使用价值。
